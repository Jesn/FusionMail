## 🔴 P0 优先级问题 (立即处理)

### 1. OAuth2 Token 刷新机制不完善

**问题描述**:
- 没有实现自动 token 刷新机制
- 当 access token 过期时，同步会失败
- 没有使用 refresh token 获取新 token
- 没有检测 token 过期时间

**为什么是问题**:
- 用户账户会频繁出现同步失败
- 需要用户手动重新授权
- 影响系统可用性和用户体验
- 可能导致邮件同步中断

**影响范围**:
- OAuth2 账户 (Gmail、Outlook)
- 同步服务 (SyncService)
- 账户管理 (AccountService)

**建议解决方案**:
1. 在 AccountService 中添加 token 过期检查
2. 实现 token 刷新逻辑
3. 在同步前自动刷新过期 token
4. 存储 refresh token 和过期时间

**代码位置**:
- backend/internal/service/account_service.go
- backend/internal/service/sync_service.go
- backend/internal/service/oauth2_service.go

**预估工作量**: 2-3 天
