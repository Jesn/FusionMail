# 短效邮箱适配器实现计划

## 实现概述

本实现计划将短效邮箱适配器功能分解为可执行的开发任务，确保与现有的标准 OAuth2 流程完全分离，同时提供完整的自动化测试覆盖。

**核心原则**：所有实现必须确保与 `backend/micro.py` 参考实现的核心流程完全一致，特别是：
1. Token 刷新流程必须使用相同的端点、参数和方法
2. 邮件获取必须使用 `/me/mailFolders/inbox/messages` 端点（不是 `/me/messages`）
3. HTTP 请求的方法、头部、参数必须与 micro.py 一致

## 技术约束

- 必须与现有的 `GraphAdapter` 完全分离
- 必须实现相同的 `MailProvider` 接口
- 必须支持现有的加密和安全机制
- 必须保持向后兼容性
- 单元测试覆盖率必须达到 80% 以上

- 性能满足设计要求（5秒内完成连接测试）
- 安全审计通过
- 文档完整且准确
