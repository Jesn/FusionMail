# 批量导入功能整合到账户表单

## 功能概述

将 Outlook/Hotmail 短效邮箱的批量导入功能整合到了单个账户添加表单中，用户现在可以通过统一的入口完成单个添加和批量导入。

## 使用方法

### 1. 打开账户添加表单

访问 http://localhost:3100/accounts 页面，点击"添加账户"按钮。

### 2. 选择 Outlook/Hotmail 提供商

在"邮箱提供商"下拉框中选择"Microsoft Outlook/Hotmail"。

### 3. 选择批量导入协议

在"协议"下拉框中，你会看到以下选项：
- **OAuth2（推荐 - 更安全）** - 标准 OAuth2 认证
- **批量导入（短效邮箱）** - 批量导入多个短效邮箱 ← 新增
- **IMAP** - IMAP 协议
- **POP3** - POP3 协议

选择"批量导入（短效邮箱）"。

### 4. 粘贴账号信息

在文本框中粘贴账号字符串，每行一个账号，格式如下：

```
email----password----refresh_token----client_id
```

示例：
```
user1@outlook.com----pass1----refresh_token_1----client_id_1
user2@hotmail.com----pass2----refresh_token_2----client_id_2
user3@outlook.com----pass3----refresh_token_3----client_id_3
```

### 5. 开始导入

点击"开始导入"按钮，系统会：
1. 显示导入进度条
2. 并行处理所有账号
3. 显示导入结果（成功/失败统计）
4. 显示每个账号的详细状态

### 6. 查看结果

导入完成后，会显示：
- 成功导入的账号数量
- 失败的账号数量
- 每个账号的详细状态和错误信息（如果有）

点击"完成"按钮关闭对话框。

## 功能特点

✅ **统一入口**：所有账户添加都从"添加账户"按钮进入  
✅ **智能切换**：根据选择的协议自动切换表单界面  
✅ **实时反馈**：显示导入进度和详细结果  
✅ **错误隔离**：单个账号失败不影响其他账号  
✅ **详细报告**：提供每个账号的导入状态和错误信息  

## 技术实现

### 前端改动

**文件**: `frontend/src/components/account/AccountForm.tsx`

1. 添加了新的协议选项：`batch_import`
2. 添加批量导入相关状态管理
3. 根据协议类型动态显示/隐藏表单字段
4. 实现批量导入处理逻辑
5. 显示导入进度和结果

### 后端 API

使用现有的批量导入 API：
- **端点**: `POST /api/v1/accounts/batch-import`
- **请求体**: `{ "accounts": ["account1", "account2", ...] }`
- **响应**: 包含成功/失败统计和详细结果

## 与原批量导入对话框的对比

| 特性 | 原批量导入对话框 | 新整合方式 |
|------|----------------|-----------|
| 入口 | 独立的"批量导入"菜单项 | 统一的"添加账户"入口 |
| 提供商选择 | 固定为 Outlook | 可选择任意提供商 |
| 协议选择 | 无 | 在协议下拉框中选择 |
| 用户体验 | 需要区分单个/批量 | 自然流畅的切换 |
| 功能完整性 | 完整 | 完整（复用相同逻辑） |

## 后续优化建议

1. **保留原批量导入入口**：作为快捷方式，直接打开批量导入模式
2. **支持更多提供商**：未来可以扩展到 Gmail 等其他提供商
3. **导入历史**：记录批量导入历史，方便追溯
4. **模板下载**：提供账号格式模板文件下载
5. **拖拽上传**：支持拖拽文本文件进行批量导入
