# FusionMail 垃圾邮件检测功能指南

## 概述

FusionMail 提供了强大的垃圾邮件检测功能，采用三层防线架构（预过滤、规则引擎、贝叶斯分类），结合白名单/黑名单机制和发件人信誉系统，实现高效、准确的垃圾邮件检测。

### 主要特性

- **高拦截率**：95%+ 的垃圾邮件拦截率
- **低误报率**：误报率低于 1%
- **高性能**：完整检测在 200ms 内完成
- **个性化**：基于用户反馈的贝叶斯学习
- **灵活配置**：支持自定义规则和阈值

## 用户使用指南

### 1. 垃圾邮件文件夹

垃圾邮件会自动移动到"垃圾邮件"文件夹。您可以：

- 在侧边栏点击"垃圾邮件"查看所有垃圾邮件
- 查看垃圾邮件的评分和检测原因
- 将误判的邮件恢复到收件箱
- 批量删除垃圾邮件
- 清空垃圾箱

### 2. 标记邮件为垃圾邮件

如果收件箱中有垃圾邮件未被检测到，您可以手动标记：

1. 打开邮件详情
2. 点击"标记为垃圾邮件"按钮
3. 邮件将移动到垃圾邮件文件夹
4. 系统会学习您的标记，提高未来的检测准确率

### 3. 恢复误判的邮件

如果正常邮件被误判为垃圾邮件：

1. 在垃圾邮件文件夹中找到该邮件
2. 点击"不是垃圾邮件"按钮
3. 邮件将恢复到收件箱
4. 系统会学习您的反馈，减少类似误判

### 4. 白名单管理

将信任的发件人添加到白名单，他们的邮件将永远不会被标记为垃圾邮件：

1. 进入"设置" > "白名单/黑名单"
2. 点击"添加白名单"
3. 输入邮箱地址或域名
4. 点击"保存"

**支持的格式**：
- 完整邮箱地址：`friend@example.com`
- 域名：`example.com`（该域名下所有邮箱都会被信任）

### 5. 黑名单管理

将已知的垃圾邮件发件人添加到黑名单，他们的邮件将直接被拦截：

1. 进入"设置" > "白名单/黑名单"
2. 切换到"黑名单"标签
3. 点击"添加黑名单"
4. 输入邮箱地址或域名
5. 点击"保存"

### 6. 查看检测详情

每封垃圾邮件都会显示详细的检测信息：

- **评分**：0-100 分，越高越可能是垃圾邮件
- **置信度**：系统对判断的确信程度
- **检测原因**：触发检测的具体原因
- **检测层级**：哪些检测层参与了判断

### 7. 个人设置

您可以自定义垃圾邮件检测的行为：

1. 进入"设置" > "垃圾邮件设置"
2. 可配置项：
   - **启用/禁用检测**：关闭后所有邮件直接进入收件箱
   - **评分阈值**：调整判定为垃圾邮件的分数线（默认 60 分）
   - **自动清理天数**：垃圾邮件保留天数（默认 30 天）

## 管理员配置指南

### 1. 系统级别设置

管理员可以配置全局的垃圾邮件检测设置：

```
设置 > 系统设置 > 垃圾邮件检测
```

- **全局开关**：启用/禁用整个系统的垃圾邮件检测
- **默认阈值**：所有用户的默认评分阈值
- **默认清理天数**：垃圾邮件默认保留天数

### 2. 规则管理

管理员可以管理垃圾邮件检测规则：

```
设置 > 垃圾邮件规则
```

#### 查看规则

- 内置规则：系统预设的 300+ 条规则，不可删除
- 自定义规则：管理员创建的规则，可编辑和删除

#### 创建规则

1. 点击"新建规则"
2. 填写规则信息：
   - **名称**：规则的描述性名称
   - **类别**：keyword（关键词）、pattern（正则）、header（邮件头）
   - **模式**：匹配的关键词或正则表达式
   - **评分**：命中时增加的分数（1-100）
3. 点击"保存"

#### 测试规则

1. 选择要测试的规则
2. 点击"测试"按钮
3. 输入测试文本
4. 查看匹配结果

#### 启用/禁用规则

- 点击规则旁边的开关即可启用或禁用
- 禁用的规则不会参与检测

### 3. 监控和统计

管理员可以查看垃圾邮件检测的统计信息：

- **检测总数**：已检测的邮件数量
- **垃圾邮件数**：被标记为垃圾邮件的数量
- **垃圾邮件率**：垃圾邮件占比
- **平均检测延迟**：检测性能指标
- **规则命中统计**：各规则的命中次数

## API 文档

### 垃圾邮件管理 API

#### 获取垃圾邮件列表

```http
GET /api/v1/spam/emails
```

**参数**：
- `page`：页码（默认 1）
- `page_size`：每页数量（默认 20）
- `account_uid`：账户 UID（可选）

**响应**：
```json
{
  "code": 0,
  "data": {
    "emails": [...],
    "total": 100,
    "page": 1,
    "page_size": 20
  }
}
```

#### 标记为垃圾邮件

```http
POST /api/v1/spam/mark
```

**请求体**：
```json
{
  "email_id": 123
}
```

#### 取消垃圾邮件标记

```http
POST /api/v1/spam/unmark
```

**请求体**：
```json
{
  "email_id": 123
}
```

#### 批量删除垃圾邮件

```http
DELETE /api/v1/spam/batch
```

**请求体**：
```json
{
  "email_ids": [123, 456, 789]
}
```

#### 清空垃圾箱

```http
POST /api/v1/spam/empty
```

## 常见问题

### Q: 为什么正常邮件被标记为垃圾邮件？

A: 可能的原因：
1. 邮件内容包含垃圾邮件常见关键词
2. 发件人信誉较低
3. 邮件格式异常（大量链接、特殊字符等）

**解决方法**：
- 将发件人添加到白名单
- 点击"不是垃圾邮件"让系统学习

### Q: 为什么垃圾邮件没有被检测到？

A: 可能的原因：
1. 垃圾邮件使用了新的伪装技术
2. 发件人信誉较高
3. 评分阈值设置过高

**解决方法**：
- 手动标记为垃圾邮件让系统学习
- 将发件人添加到黑名单
- 降低评分阈值

### Q: 如何提高检测准确率？

A: 建议：
1. 积极标记误判的邮件（无论是漏检还是误检）
2. 维护白名单和黑名单
3. 等待贝叶斯模型训练完成（需要 50 封标记邮件）

### Q: 垃圾邮件会自动删除吗？

A: 是的，默认 30 天后自动删除。您可以在设置中调整保留天数。

### Q: 关闭垃圾邮件检测后会怎样？

A: 所有邮件将直接进入收件箱，不会进行任何垃圾邮件检测。
