## 3. 邮件同步流程

```
┌─────────────────────────────────────────────────────────────┐
│                    定时任务触发                              │
│              (Cron: 每 N 分钟执行一次)                      │
└────────────────────┬────────────────────────────────────────┘
                     │
┌────────────────────▼────────────────────────────────────────┐
│              SyncService.SyncAccount()                       │
│                                                              │
│  1. 获取账户配置                                            │
│  2. 解密凭证                                                │
│  3. 创建适配器                                              │
└────────────────────┬────────────────────────────────────────┘
                     │
┌────────────────────▼────────────────────────────────────────┐
│              Adapter.Connect()                              │
│                                                              │
│  1. 建立连接 (TLS/SSL)                                      │
│  2. 认证                                                    │
│  3. 测试连接                                                │
└────────────────────┬────────────────────────────────────────┘
                     │
┌────────────────────▼────────────────────────────────────────┐
│              确定同步起始时间                                │
│                                                              │
│  首次同步: 7 天前                                           │
│  后续同步: 上次同步时间 - 5 分钟                            │
└────────────────────┬────────────────────────────────────────┘
                     │
┌────────────────────▼────────────────────────────────────────┐
│              Adapter.FetchEmails()                          │
│                                                              │
│  1. 查询邮件列表                                            │
│  2. 获取邮件详情                                            │
│  3. 解析邮件内容                                            │
└────────────────────┬────────────────────────────────────────┘
                     │
┌────────────────────▼────────────────────────────────────────┐
│              去重检查                                        │
│                                                              │
│  检查 (provider_id, account_uid) 是否存在                   │
│  存在: 更新邮件                                             │
│  不存在: 创建新邮件                                         │
└────────────────────┬────────────────────────────────────────┘
                     │
┌────────────────────▼────────────────────────────────────────┐
│              应用规则                                        │
│                                                              │
│  1. 获取账户的所有规则                                      │
│  2. 按优先级排序                                            │
│  3. 逐条检查和执行                                          │
└────────────────────┬────────────────────────────────────────┘
                     │
┌────────────────────▼────────────────────────────────────────┐
│              记录同步日志                                    │
│                                                              │
│  1. 记录同步状态                                            │
│  2. 记录邮件数量                                            │
│  3. 记录错误信息                                            │
└────────────────────┬────────────────────────────────────────┘
                     │
┌────────────────────▼────────────────────────────────────────┐
│              同步完成                                        │
│                                                              │
│  更新账户最后同步时间                                       │
└─────────────────────────────────────────────────────────────┘
```

## 6. 数据流向

```
用户操作
   │
   ▼
React 组件
   │
   ├─ 更新 Zustand Store
   │
   ▼
API 服务层 (Axios)
   │
   ├─ 添加 JWT Token
   ├─ 错误拦截
   └─ 响应转换
   │
   ▼
后端 API (Gin)
   │
   ├─ 认证中间件
   ├─ 速率限制中间件
   └─ 日志中间件
   │
   ▼
Handler 层
   │
   ├─ 请求验证
   └─ 参数解析
   │
   ▼
Service 层
   │
   ├─ 业务逻辑处理
   └─ 调用 Repository
   │
   ▼
Repository 层
   │
   ├─ 数据库查询
   └─ 缓存操作
   │
   ▼
数据库 / 缓存
   │
   ├─ PostgreSQL
   └─ Redis
   │
   ▼
响应返回
   │
   ├─ JSON 格式
   └─ 状态码
   │
   ▼
前端处理
   │
   ├─ 更新 Store
   ├─ 显示数据
   └─ 显示提示
```

## 7. 认证流程

```
┌─────────────────────────────────────────────────────────────┐
│                    用户登录                                  │
└────────────────────┬────────────────────────────────────────┘
                     │
        ┌────────────┴────────────┐
        │                         │
┌───────▼────────┐      ┌────────▼────────┐
│ 密码登录        │      │ OAuth2 登录     │
│                │      │                 │
│ 1. 输入用户名  │      │ 1. 点击按钮     │
│ 2. 输入密码    │      │ 2. 重定向授权   │
│ 3. 验证密码    │      │ 3. 用户授权     │
│ 4. 生成 JWT    │      │ 4. 回调获取码   │
│                │      │ 5. 交换 token   │
└───────┬────────┘      └────────┬────────┘
        │                        │
        └────────────┬───────────┘
                     │
┌────────────────────▼────────────────────────────────────────┐
│              返回 JWT Token                                 │
│                                                              │
│  {                                                           │
│    "token": "eyJhbGc...",                                   │
│    "expiresAt": "2025-11-06T10:00:00Z",                     │
│    "user": { "id": 1, "email": "user@example.com" }         │
│  }                                                           │
└────────────────────┬────────────────────────────────────────┘
                     │
┌────────────────────▼────────────────────────────────────────┐
│              前端存储 Token                                  │
│                                                              │
│  - localStorage 或 sessionStorage                           │
│  - Zustand authStore                                        │
└────────────────────┬────────────────────────────────────────┘
                     │
┌────────────────────▼────────────────────────────────────────┐
│              后续请求携带 Token                              │
│                                                              │
│  Authorization: Bearer eyJhbGc...                           │
└────────────────────┬────────────────────────────────────────┘
                     │
┌────────────────────▼────────────────────────────────────────┐
│              后端验证 Token                                  │
│                                                              │
│  1. 提取 Token                                              │
│  2. 验证签名                                                │
│  3. 检查过期时间                                            │
│  4. 获取用户信息                                            │
└────────────────────┬────────────────────────────────────────┘
                     │
        ┌────────────┴────────────┐
        │                         │
┌───────▼────────┐      ┌────────▼────────┐
│ Token 有效      │      │ Token 无效      │
│                │      │                 │
│ 继续处理请求    │      │ 返回 401        │
│                │      │ 前端重定向登录  │
└────────────────┘      └─────────────────┘
```
